# Security policy

Pretzel is research code. It has not been audited.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/a16z/pretzel/security/advisories/new)
through **Security → Report a vulnerability** on the repository. Do not file a
vulnerability as a public issue.
If that is unavailable, email both maintainers:

- Alberto Centelles <[zk_albi@proton.me](mailto:zk_albi@proton.me)>
- Justin Thaler <[justin.r.thaler@gmail.com](mailto:justin.r.thaler@gmail.com)>

Include the affected commit, the parameter set (Pretzel-(3,3), Pretzel-(4,4) or
Pretzel-(5,5)), reproduction steps or a reproducer, expected and observed
outcomes, and the potential impact.

Keep sensitive details in the private report, not in public issues or
discussions.
